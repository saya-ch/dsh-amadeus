# 发布流程

> 本仓库产出**两个独立产物**，版本与发布节奏互不干扰。

| 产物 | 标识 | 分发渠道 |
|:---|:---|:---|
| **Host 插件** | npm 包 `dsh-amadeus@x.y.z` | npm（`package.json` 版本） |
| **Android App** | `com.amadeus.whale` v`x.y.z` | GitHub Releases（APK 附件） |

---

## 一、版本号规范

统一 **语义化版本 `MAJOR.MINOR.PATCH`**。

| 位 | 何时 +1 |
|:---|:---|
| `MAJOR` | 协议不兼容变更（`[[AMW:]]` 标签格式、REST 路由破坏性改动） |
| `MINOR` | 向后兼容的新功能（新窗口类型、新 provider） |
| `PATCH` | Bug 修复、文案、素材替换 |

**Android 额外要求**：`versionCode` 必须**单调递增**（同版本号不可重复发），由 CI 自动换算：

```
versionCode = MAJOR × 10000 + MINOR × 100 + PATCH
例：0.1.0 → 100   1.3.2 → 10302
```

---

## 二、Tag 规范

| Tag | 含义 |
|:---|:---|
| `app-v0.1.0` | **Android App 发布**（触发 CI 打包 + 建 Release） |
| `v0.1.0` | Host 插件发布（npm，手动 `npm publish`） |

> ⚠️ App 与插件用**不同前缀**，避免 npm 版本与 App 版本互相顶掉。

---

## 三、App 发布

### 方式 A：本地打包（推荐用于首次发布 / 紧急热修）

```bash
# 1. 确认签名凭据存在（keystore.properties 已被 .gitignore 忽略）
ls app/amadeus-android/keystore.properties
ls app/amadeus-android/keystore/amadeus-release.jks

# 2. 打包（versionCode/Name 可被环境变量覆盖）
cd app/amadeus-android
AMADEUS_VERSION_NAME=0.1.0 AMADEUS_VERSION_CODE=100 \
  ./gradlew :app:assembleRelease --console=plain

# 3. 校验签名
"$ANDROID_HOME/build-tools/35.0.0/apksigner" verify --print-certs \
  app/build/outputs/apk/release/app-release.apk

# 4. 上传到 GitHub Release（资产名固定为 amadeus.apk，见第五节）
cp app/build/outputs/apk/release/app-release.apk amadeus.apk
gh release create app-v0.1.0 amadeus.apk \
  --title "Amadeus App v0.1.0" --generate-notes
```

### 方式 B：CI 自动发布

打 tag 即全自动（测试 → 构建 → 校验签名 → 建 Release）：

```bash
git tag app-v0.1.0
git push origin app-v0.1.0
```

也可在 **Actions → Android Release → Run workflow** 手动填版本号触发。

流程见 [`.github/workflows/android-release.yml`](../.github/workflows/android-release.yml)：

```
解析版本号 → 还原签名密钥 → 单元测试 → assembleRelease
          → apksigner 校验 → 创建 Release（资产 amadeus.apk）
```

## 四、签名密钥管理（**最关键**）

> ⚠️ **丢失密钥 = 永远无法发布可覆盖安装的更新**。Android 靠签名判定"同一个 App"，
> 换密钥后老用户必须卸载重装。

### 凭据位置（均不入库）

| 文件 | 说明 |
|:---|:---|
| `app/amadeus-android/keystore/amadeus-release.jks` | 密钥库（RSA 4096，有效期 10000 天） |
| `app/amadeus-android/keystore.properties` | 密码与别名（明文，**已 gitignore**） |

密钥信息：

```
别名 alias : amadeus
证书 DN    : CN=Amadeus, OU=Whale, O=saya-ch, C=CN
```

### 备份清单（请立刻做）

1. `amadeus-release.jks` 复制到**至少两处**离线/私密位置
2. `keystore.properties` 的密码抄进密码管理器
3. 记录证书指纹，便于日后核对：

```bash
keytool -list -v -keystore app/amadeus-android/keystore/amadeus-release.jks -alias amadeus | grep SHA256
```

### 配置 CI Secrets

CI 需要 4 个 secret（`Settings → Secrets and variables → Actions`，或用 gh）：

```bash
# 1) 密钥库 → base64 单行
base64 app/amadeus-android/keystore/amadeus-release.jks | tr -d '\n' > /tmp/ks.b64
gh secret set AMADEUS_KEYSTORE_BASE64 < /tmp/ks.b64

# 2) 其余三项（密码取自 keystore.properties）
gh secret set AMADEUS_KEY_ALIAS      --body 'amadeus'
gh secret set AMADEUS_KEYSTORE_PASSWORD
gh secret set AMADEUS_KEY_PASSWORD

rm -f /tmp/ks.b64   # 用完即删
```

| Secret | 用途 |
|:---|:---|
| `AMADEUS_KEYSTORE_BASE64` | 密钥库内容（base64） |
| `AMADEUS_KEYSTORE_PASSWORD` | 库密码 |
| `AMADEUS_KEY_ALIAS` | 别名（`amadeus`） |
| `AMADEUS_KEY_PASSWORD` | 密钥密码 |

> 若 secret 缺失：`release` 构建产出**未签名 APK**（不报错），CI 会在"校验签名"步骤拦住并失败。

## 五、产物命名与下载链接

CI 把 APK 重命名为**固定名** `amadeus.apk`，因此可用 GitHub 的稳定下载地址：

```
https://github.com/saya-ch/dsh-amadeus/releases/latest/download/amadeus.apk
```

- `latest` 永远指向**最新一个正式 Release**
- 因此：**App 走 GitHub Release，插件走 npm** —— 不要让插件也建 Release，否则 `latest` 会被顶掉

| 链接 | 含义 |
|:---|:---|
| `/releases/latest/download/amadeus.apk` | 始终下载最新 APK |
| `/releases` | 全部版本列表（含历史版本） |

## 六、首次发布 checklist

- [x] 生成 release keystore（`keystore/amadeus-release.jks`）
- [x] `keystore.properties` 就位且被 `.gitignore` 覆盖
- [ ] **备份密钥库 + 密码**（第四节）
- [ ] 配置 4 个 CI secrets
- [ ] `./gradlew :app:assembleRelease` 本地通过
- [ ] `apksigner verify` 通过
- [ ] 打 tag `app-v0.1.0` 并推送
- [ ] Release 页面确认 APK 可下载、可安装

## 八、回滚与热修

| 场景 | 做法 |
|:---|:---|
| App 有严重 Bug | 修完发 **PATCH**（`0.1.0 → 0.1.1`，versionCode 必须 +1） |
| 版本完全不可用 | Release 页面把它标为 **Pre-release**，`latest` 自动退回上一个正式版 |
| 误发布 | `gh release delete app-v0.1.0 --cleanup-tag`，重打 tag |

> App 不支持"降级安装"：版本号只能前进，`versionCode` 相同的包无法覆盖。

├─ 26.4 MB  TTF（maruko 花丸圆体，CJK 全量，用于任意中文对话）

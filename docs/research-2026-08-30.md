## 1. DeepSeek Harness 插件开发规范

- **权威指南**: `moneka123/deepseek-harness-plugin-dev-guide` [github.com/moneka123/deepseek-harness-plugin-dev-guide](https://github.com/moneka123/deepseek-harness-plugin-dev-guide)
  - 四份核心文档: AGENTS.md (总则必读) / REFERENCE.md (扩展点) / INSTALLATION.md (Bundle/Patch/Profile) / DYNAMIC-PLUGINS.md (动态 Cordis)
  - 核心原则: 最小侵入、源码为准、生命周期用 `ctx.effect()` + disposer、配置用 `cordis.patch.yml` 覆盖、源码一定不要动 (用户特别强调)
  - 扩展点选择: `tools` / `systemPrompt` / `agent` / `llm` / `jobs` 等，Amadeus 的高权限人格应走 `systemPrompt` + `permission-presets`
  - 双端沙箱: Host / Client 分离，Client 注入需走 `dsh.bundle` 的 `client.inject`
  - 验证: `--dump-config` 审计最终配置，P0-P2 分级测试，HMR 卸载验证无残留
  - 基线 revision: `3bbc502cd2b122fe7d1c4a4562ae8cd51ca1c1a7`，需与当前 `deepseek-harness` 的 HEAD 核对

- **关键约束**
  - `node:vm` 非安全沙箱，工具隐藏 ≠ 授权
  - 所有资源必须可取消、可卸载、可热重载
  - Bundle/Patch/Profile 装配顺序决定最终配置

## 3. 社区桌面鲸鱼娘参考

- **dsh-whale-girl** `nickkkkkk123123/dsh-whale-girl` [github.com/nickkkkkk123123/dsh-whale-girl](https://github.com/nickkkkkk123123/dsh-whale-girl)
  - 核心: DSH Desktop 右下角灵动挂件，946行？实际安装包 346KB，立绘量化至 46KB，无额外进程，省电模式 60s 暂停动画
  - 功能: 余额/用量/上下文进度条、峰谷提醒、彩蛋气泡、右键菜单、音效(可爱/鸭叫)、甩抛弹跳、中键弹弓、水滴连接线、毛玻璃强度 0-16
  - 配置: `~/.dsh/.whale-girl-config.json` (soundMode, showProgress, frost, panelOpacity 等)
  - 技术亮点: 图片/音效内嵌 data URL (绕过 DSH Desktop 403 认证), 宿主通过 `webserver/index-inject` + `postMessage` 广播数据，`credentials.resolve('DEEPSEEK_API_KEY')` 读余额
  - 可参考: 拖动物理、省电策略、毛玻璃、气泡随机台词、余额探测逻辑
  - 源码: `pnpm install / build` 即 host + client 双端

- 其他鲸鱼相关: `dsh-whale-desktop-launcher` (启动器), `DSH-Whale-Balance-Widget` (余额挂件)

## 4. 对 Amadeus: Whale 的启示

- **不要动源码**: 必须走 `dsh-amadeus` 插件 + `cordis.patch.yml`，Mode 人格用 `dsh-persona` 的 `complete: true` 覆盖 `deployment:persona`，权限走 `permission-presets` 的 `danger-full-access`
- **APP 复用**: 复用 `dsh-mobile` 的 gateway 证书/配对/发现，但剧场用 Compose 原生，标签协议 `[[AMW:]]` 在 Host 层 `ensureTag` 兜底
- **桌面鲸鱼娘可复用**: 拖动/弹跳/省电/毛玻璃 的缓动与物理可直接抄 `dsh-whale-girl` 的实现，立绘压缩方案也值得抄 (46KB 技巧)
